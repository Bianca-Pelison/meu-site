#  Site do Sport Club Internacional

##  Sobre o projeto

Este projeto consiste em uma Landing Page sobre o Sport Club Internacional,
desenvolvida como atividade da Unidade Curricular de Versionamento e Colaboração.

O objetivo do projeto é aplicar na prática os conhecimentos de Git, GitHub,
commits, branches, merge, resolução de conflitos e versionamento.

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

##  Como executar o projeto

1. Clone este repositório:
   https://github.com/Bianca-Pelison/meu-site.git

2. Entre na pasta do projeto.

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code.
